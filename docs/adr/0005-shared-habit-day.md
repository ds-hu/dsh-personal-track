# **习惯日**的算术放在 `src/shared`，两半身共用一份

**习惯日**原本只有宿主一份实现（`src/host/daykey.ts`），浏览器半身在 `src/client/board/format.ts` 里手抄了 `shiftKey`、`daysBetweenKeys` 与"周末是哪天"，而**专注模式**更进一步，用本地日历日冒充"今天"。于是**夜段**（00:00–04:00）里，同一个任务在**专注模式**里显示"今天"、在看板卡片上显示"3 天后"——两处都"对"，只是量的是不同的日子。我们把该模块移到 `src/shared/habit-day.ts`（连 `DayBoundary` 与新增的 `daysBetween` 一起），客户端只从它取日期算术，`今天` 一律来自宿主的 `ClockView`。**专注模式**因此多了一个必填的 `today` prop：它不再有权自己造一个日期。

- **Status**: accepted
- **Considered Options**
  - 保留客户端镜像 —— 否决，它已经漂过一次，而且没有东西能发现下一次。
  - 把客户端的日期算术搬进宿主 —— 否决：导航发生在浏览器，行不通的方向。
  - 让客户端只做字符串切片、不碰 `Date` —— 否决：`周几`、跨月、**到期带**都要真正的日历算术，复习一遍就是第三份实现。
- **Consequences**
  - 模块必须保持同构（只用 `Date` 与 `Intl`，不引 `node:`、不碰 DOM），这条写进了文件头；两个 tsconfig 都编译它。
  - **到期带**的分档（当天 / 三日内 / 七日内）仍是显示规则，留在客户端，但量距建在这份算术之上。
  - `weekEndKey`（新任务**截止**的初值）也只剩一处实现。
